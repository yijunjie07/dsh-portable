DeepSeek Harness 便携版

Mac（Apple Silicon）：双击 DSH-Mac.command
  第一次在某台 Mac 上运行，若提示"无法验证开发者"，右键 → 打开。
Windows（64 位）：双击 DSH-Windows.bat

启动后浏览器会自动打开 DeepSeek Harness 网页版。
用完关掉那个黑色的命令行窗口即可。

home\            你的配置、API key、会话记录（两个系统共用）
dsh-*.dmg/.iso   程序镜像（只读，不要改）
dsh-win-x64\     只在不能挂载镜像的 Windows 电脑上才会出现，可以删掉

注意：home\ 里有你的 API key，U 盘丢了请到 DeepSeek 平台重置 key。
